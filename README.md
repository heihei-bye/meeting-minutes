# 会议纪要助手

AI 驱动的会议纪要生成工具。粘贴会议转录文本，一键生成结构化纪要。

## 功能

- 支持多家 AI 服务商（DeepSeek、通义千问、智谱、月之暗面等）
- 自动生成：标题、摘要、议题、决策、行动项
- 手机浏览器直接访问

## 使用

1. 选择 AI 服务商
2. 输入对应的 API Key
3. 粘贴会议转录文本
4. 点击「生成会议纪要」
